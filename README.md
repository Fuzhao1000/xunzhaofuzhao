# 寻找伏昭

一张名字叫**寻找伏昭**的冒险 RPG 我的世界地图(Minecraft 1.20.1 Forge)。跟着任务书探索世界、挑战 Boss、揭开伏昭的秘密,走出属于你的结局。

本仓库存放的是**地图存档**(Skyland),已清除所有玩家存档信息,下载后即是从零开始的完整地图。

## 游玩方法

### 0. 前置:必须使用配套整合包

本地图是重度 mod 定制地图(约 79 个 mod),机关、任务、Boss 全部依赖 mod 和 KubeJS 脚本运行。
**只下载存档、不装整合包是玩不了的。** 需要先获取"寻找伏昭整合包"(PCL2 整合包,自带 1.20.1-Forge_47.4.22 与全部 mod,开箱即玩)。

### 1. 下载存档

点击本页面右上角 **Code → Download ZIP**,解压后取出 `Skyland` 文件夹;
或者用 git:

```
git clone https://github.com/Fuzhao1000/xunzhaofuzhao.git
```

### 2. 放入存档

整合包是版本隔离布局,把 `Skyland` 文件夹放到:

```
寻找伏昭整合包/versions/1.20.1-Forge_47.4.22/saves/Skyland
```

(saves 文件夹不存在就手动新建一个)

### 3. 启动游戏

1. 双击整合包里的 `Plain Craft Launcher 2.exe`
2. 版本会自动选中 1.20.1-Forge_47.4.22,直接点**启动游戏**
3. 首次启动较慢请耐心等待;提示 Java 问题就在 设置 → Java 里选包内的 `jre17\bin\javaw.exe`
4. 内存建议 4G 以上:设置 → 内存 调到 4096

### 4. 开始游玩

- 单人游戏 → 选择存档**寻找伏昭**进入
- 地图为**冒险模式**:不能破坏/放置方块,但按钮、箱子、NPC 都可以交互
- 进度系统已禁用,一切跟着 **FTB Quests 任务书**(默认按键打开)走主线即可
- 地图内有隐藏结局,探索得越深,离真相越近……

### 5. 联机游玩

需要主机开服务器并用内网穿透(如 SakuraFrp)映射 25565 端口:

1. 主机:配置好服务端后,在 SakuraFrp 创建 TCP 隧道(本地端口 25565),获得"域名:端口"地址
2. 朋友:多人游戏 → 添加服务器 → 填入该地址
3. 服务器为离线模式,随便填用户名即可进入,无需正版账号

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 提示 Java 版本错误 | 设置 → Java,指向包内 `jre17\bin\javaw.exe` |
| 启动卡顿 / 内存不足 | 设置 → 内存调到 4096 以上 |
| 游戏内不是冒险模式 | 输入 `/gamemode adventure` |
| 箱子打不开 / 机关没反应 | 确认用的是配套整合包,且 mod 数量完整 |

祝玩得开心!
